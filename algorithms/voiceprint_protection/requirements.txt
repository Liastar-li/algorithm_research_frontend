# 【实测结论，别再重复踩】
#   * PyPI 上的 torch==2.4.1（Windows 轮子）是 **CPU-only**，
#     实测装出来是 "2.4.1+cpu"，torch.cuda.is_available() == False。
#     国内 PyPI 镜像（清华/阿里/中科大）只同步 PyPI，因此**都给不了 CUDA 版**。
#   * 带 "+cu121" 本地版本号的 CUDA 轮子**只存在于 PyTorch 官方索引**
#     （以及少数镜像了官方索引的国内源）。
#   * 阿里云 pytorch-wheels 对部分网络段直接 403：
#     "X-Tengine-Error: denied by IP ACL = blacklist" —— 不是路径写错。

#       python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available())"

#       -> "2.4.1+cpu None False" 是**预期的**：这是 CPU 版。
#          本项目**开发阶段用 CPU 版完全够**（L0 平台打通、L1 推理链、评测都能跑），
#          Stage 1/2 训练放到云上（云机用 PyTorch 预置镜像，零下载）。
#          所以这一步**不需要任何额外操作**，直接进步骤 2。
#       -> 若要本地 GPU 训练，用下面的【步骤 1B】换成 CUDA 版。

# 【步骤 1B：换成本地 CUDA 版】

#   ★ 已实测可用（2026-11，RTX 4060 Laptop 实测通过，sha256 与官方完全一致）：

#         -f https://mirror.nju.edu.cn/pytorch/whl/cu121/torch/ `

#         -i https://pypi.tuna.tsinghua.edu.cn/simple

#     装完立刻验证（期望 2.4.1+cu121 12.1 True + 显卡型号）：

#       python -c "import torch, torchaudio; print(torch.__version__, torch.version.cuda, torch.cuda.is_available()); print(torch.cuda.get_device_name(0))"
#
#     实测输出：
#       2.4.1+cu121 12.1 True
#       NVIDIA GeForce RTX 4060 Laptop GPU

#   【注意】上面这些是"普通文件链接"(find-links)，不是 simple index，
#   所以要用 -f 而不是 --index-url，且 torchaudio 要单独给一个 -f。
#   装好后确认 torch.__version__ 带 "+cu121" 后缀——
#   如果显示 "2.4.1"（无后缀），说明装成了 CPU 版，需 --force-reinstall 重来。

# --- 数值与音频 ---
numpy==1.26.4            # 必须 <2.1：numba 0.60 要求 numpy<2.1；librosa 0.10 需 numpy<2
scipy==1.13.1            # numpy<2.3，与 numpy 1.26.4 兼容
librosa==0.10.2.post1    # 音频读取、mel、STFT
soundfile==0.12.1        # wav 读写（比 librosa 的 io 更少依赖）
soxr==0.3.7              # 高质量重采样，librosa resample 可选后端

# --- 第三方组件的依赖（GE2E 说话人编码器）---
# ⚠️ 上游 Real-Time-Voice-Cloning 的 encoder/model.py 在 import 时就要
#    `from sklearn.metrics import roc_curve`，所以**必须装 scikit-learn**，
#    否则 `import encoder.inference` 直接 ImportError，桥接层起不来。
#    1.5.2 是同时支持 Python 3.9 与 numpy<2 的最后一个稳定系列。
scikit-learn==1.5.2
#
# 可选（不装也能跑，只是静音不会被裁掉，嵌入质量略有差别）：
#   webrtcvad==2.0.10     # 上游用来裁长静音；缺失时上游会自己 try/except 跳过

# --- 训练与可视化 ---
tqdm==4.66.4
tensorboard==2.16.2      # torch 2.4 要求 tensorboard >=2.14,<2.17
matplotlib==3.8.4        # 训练曲线、t-SNE 图（复现论文 Figure 2 / Figure 3）

# --- 服务化（平台算法服务）---
fastapi==0.110.3
uvicorn[standard]==0.30.1
# ⚠️ 版本号很关键：python-multipart <= 0.0.9 提供的模块名是 multipart，
#    而 FastAPI 0.110.3 依赖的 starlette 0.37 只会 `import python_multipart`，
#    装了 0.0.9 会出现"pip 显示已安装、import 却失败"，
#    并且起服务时报 'Form data requires "python-multipart"'。
#    >= 0.0.10 才提供 python_multipart 模块；这里取 0.0.20（含 DoS 修复）。
python-multipart==0.0.20
pydantic==2.7.4
requests==2.32.3

# --- 语音识别（算 WER 用）---
#
# 默认用 faster-whisper 而不是 openai-whisper，原因：
#   openai-whisper 的 setup.py 无条件依赖 triton>=2.0.0，PyPI 没有 Windows 轮子，
#   Windows 上直接 pip install openai-whisper 会在解析 triton 时失败。
#   faster-whisper 是 CTranslate2 实现，模型与论文一致（large-v3），纯 pip 可装，
#   转写结果与 openai-whisper 等价，足够计算 WER。
huggingface_hub==0.24.6  # 同时也用于 torch.hub.load('NVIDIA/torch.hifi_gan', ...)
tokenizers==0.19.1
ctranslate2==4.5.0
faster-whisper==1.1.0
jiwer==3.0.4             # WER 计算（论文用 Whisper-large 算 WER）
numba==0.60.0            # librosa 依赖
llvmlite==0.43.0         # numba 0.60 的后端

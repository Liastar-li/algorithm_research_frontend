# ----------------------------------------------------------------------------
# PyTorch 官方 CUDA 轮子索引
#
# 为什么用 --extra-index-url 而不是 --index-url：
#   --index-url 会"顶掉" PyPI，装 torch 时可能连带找不到 PyPI 上的依赖。
#   --extra-index-url 是"多一个源"，PyPI 仍然是主源。
#
# 为什么写 torch==2.4.1+cu121 这种带 +cu121 的完整版本号：
#   PyPI 上的 torch 是 2.4.1（不带 CUDA 标记），本机 +cu121 的轮子只存在于
#   PyTorch 官方索引。写死 +cu121 可以保证绝不会误装成 CPU 版或 CUDA 12.4 版。
#
# 关于 cu121 与本机驱动：cu121 轮子要求 NVIDIA 驱动 >= 525.60.13。
#   本机实测 Driver 566.24 / CUDA 12.7 -> 满足要求，可以直接用。
#   若换机器报 "CUDA driver version is insufficient"，见 README.md 的换卡说明。
# ----------------------------------------------------------------------------
--extra-index-url https://download.pytorch.org/whl/cu121
